## How to read the table

1. **MID is the clean case** (bracketed by IN and OUT): ANY 0.877 and SCINT_ANY 0.875 agree in REF - two independent
   references, no reconstruction in the second. ~12 % of the muons leave **no hit at all** in P2_MID; no position or
   cluster definition can recover these. They are the threshold losses (beam autopsy).
2. Position-requiring definitions are lower: A20 0.82, HIT15 0.83 for MID; for IN/OUT HIT15 0.74-0.75. The difference
   ANY - HIT15 (5-13 points) = muons where the chamber fired but not near the prediction: tag jitter / wrong tag
   cluster / resolution, i.e. the **efficiency calculation**, and it is on top of the electronics gap.
3. COUNT for IN/OUT (0.89-0.91) is **above** ANY (0.87): the counting estimator is not an absolute number (finding 8);
   use the muon-level definitions for anything quoted.
4. bscan rows: HIT15 far below ANY (MID bscan_hvon10 0.23 vs 0.85) while SCINT_ANY stays 0.87 - the chambers fire but
   the predictions are wrong in those configurations (noisy tags?). ANY/HIT15 have no side-band subtraction yet, so
   noise inflates ANY in noisy configurations. Open point.
5. Dream vs VMM on the same connectors stays 4-10 points (OUT, MID) whatever the VMM definition: the gap is electronics.

## Multi-cluster tags: how many muons leave the sample (`tag_rejects.py`, 19 Nov evening)

All weekend runs except the pulser runs 270/283 (17 runs, 54 367 scintillator coincidences), condor 13754354; outputs
`$W/analysis/tag_rejects/run*.json`, `summary_chambers.csv`, `summary_probes.csv` (`tag_rejects_summary.py`).
For every scintillator hit, each chamber's time groups (gap 100 ns) with a hit 140-310 ns later are classified with
exactly the `efficiency_tp.py` cuts; random rates from the same window 4 us later (<= 0.4 %, subtracted).

| | P2_IN | P2_MID | P2_OUT |
|---|---|---|---|
| active chamber, group rejected (not a tag) | 10.1 % | 7.6 % | 5.5 % |
| reason: too wide (> 15 mm from the mean) | 91 % | 93 % | 92 % |
| reason: > 6 pads (always also wide) | 9 % | 6 % | 7 % |
| burst / dead pad | <= 1 % | <= 1 % | <= 1 % |
| rejected group = 1 blob / 2 / >= 3 spatial pieces | 1 / 53 / 47 % | 1 / 58 / 42 % | 1 / 57 / 42 % |
| as probe: muons with both tags active that are LOST | 11.4 % | 14.4 % | 15.8 % |
| ... of which one tag was clean | 80 % | 86 % | 82 % |
| probe any-hit, USED muons | 0.732 | 0.827 | 0.705 |
| probe any-hit, LOST muons | 0.745 | 0.853 | 0.724 |

(IN/OUT any-hit includes the extrapolation acceptance; MID is the bracketed number.)

Reading:
- 11-16 % of the tag-confirmed muons leave the sample, almost always because ONE tag chamber has a second (or third)
  piece more than 15 mm away within 100 ns - never one large blob, almost never bursts or dead pads.
- The lost muons fire the probe slightly MORE often (+1-3 points; MID +2.6 +- ~0.8). Dropping them biases the
  efficiency by about 0.15 x 0.02 = **~0.3 points (downwards)** - small next to the 4-10 point gap; recovering them
  mostly buys statistics (+13-19 %). The excess may also be correlated activity (showers) rather than efficiency.
- Same pattern in every configuration; gain 9 has fewer rejects (fewer hits overall).
- Open: what the extra pieces are (crosstalk on the same chip / connector at fixed channel offsets, delta electrons,
  noise). That decides the picker (largest-ADC piece, in-time with the scintillator, line through both paddles).
